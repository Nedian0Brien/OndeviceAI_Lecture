# 손마디 천지인 입력기

엄지로 같은 손의 손가락 마디를 **누르면 그 천지인 키를 입력하고, 주먹을 쥐면 지우는** 카메라 프로젝트입니다. 손바닥 중앙에는 엄지와 가장 가까운 키를 누르면 들어갈 자모를 표시합니다. 카메라 영상 위에 손마디 자판과 한글 입력 결과를 HUD로 표시하며 `S`로 UTF-8 텍스트 파일에 저장합니다. 다른 프로그램에 키 입력을 전달하는 OS 입력기는 포함하지 않습니다.

## 손 위 키 배치

손바닥이 카메라를 향하도록 손을 세우고 손가락을 편 상태에서 사용합니다.
- 열: 검지·중지·약지·소지 네 손가락
- 행: 위에서부터 끝마디(DIP–손끝), 중간마디(PIP–DIP), 뿌리마디(MCP–PIP)
- 엄지 끝은 MediaPipe landmark 4번입니다. 지움은 키가 아니라 주먹입니다.

| | 검지 | 중지 | 약지 | 소지 |
| --- | --- | --- | --- | --- |
| 끝마디 | 1: ㅣ | 2: ㆍ | 3: ㅡ | 0: ㅇ→ㅁ |
| 중간마디 | 4: ㄱ→ㅋ→ㄲ | 5: ㄴ→ㄹ | 6: ㄷ→ㅌ→ㄸ | 공백 |
| 뿌리마디 | 7: ㅂ→ㅍ→ㅃ | 8: ㅅ→ㅎ→ㅆ | 9: ㅈ→ㅊ→ㅉ | 확정 |

- 검지~약지는 기존 천지인 배열(모음 / ㄱㄴㄷ / ㅂㅅㅈ)을 그대로 둡니다. 소지에는 ㅇㅁ, 공백, 확정(Tab과 같음)을 둡니다.
- 키는 손가락 기준으로 놓입니다. 그래서 왼손과 오른손에서 같은 손가락에는 같은 키가 놓이고, 화면에서 보이는 좌우 순서는 손에 따라 반대가 됩니다.
- 각 마디의 중점에 `ㅣ`, `ㄱㅋ`처럼 자판 글자를 작은 원형 키로 표시합니다. `project01.py`의 `KEY_MAP`이 배열이고, 마디 정의는 `tap_detect.SEGMENTS`입니다.

영상 크기를 유지하며 별도 패널 없이 UI를 합성합니다. visionOS의 [유리 재질](https://developer.apple.com/design/human-interface-guidelines/materials)과 [원형·캡슐 버튼](https://developer.apple.com/design/human-interface-guidelines/buttons)을 참고해, 중성 톤의 반투명 재질과 얇은 반사 테두리를 사용합니다. 유리 표면 안의 영상만 살짝 흐리게 합니다. 인식된 양손에는 옅은 손바닥 mesh·관절 연결선과 왼손/오른손 이름을 표시하고, 각 엄지 끝에는 흰색 링과 점으로 인디케이터를 표시합니다. OpenCV/Pillow로 표현한 2D 스타일이며 visionOS 네이티브 재질은 아닙니다.

상단 입력창은 내용에 맞춰 폭이 변하는 작은 캡슐이며 **현재 줄의 끝부분 한 줄**만 보여줍니다. 긴 줄의 앞부분은 `…`로 생략해도 전체 입력은 조합기에 보존되고 S로 저장됩니다. 각 손의 엄지와 가장 가까운 키는 밝아지고 최대 30% 커지며, 크기는 짧게 보간해 부드럽게 전환합니다. 손바닥 중앙의 원형 미리보기에는 `ㄱㅋ` 같은 키 묶음 대신 다음에 입력할 자모 한 개를 보여줍니다. 같은 자음 키의 연속 입력이라면 `ㅋ`, `ㄲ`처럼 다음 순환 자모를 보여줍니다.

주먹을 쥐는 동안에는 손가락 자판을 숨기고, 손바닥 원에 `지움`과 주먹 유지 진행 표시를 보여줍니다. 입력이나 지움이 일어나면 해당 키가 짧게 흰색으로 점등합니다. 안내 문구는 다음 상황에서만 짧게 표시합니다. 저장과 판정 거리 변경 알림은 2.5초 뒤 사라집니다.
- 손을 찾는 중
- 엄지를 손가락에서 떼야 할 때
- 일시정지 중 `H`로 전체 도움말과 진단 정보를 확인할 수 있으며, 도움말을 연 동안 손 입력은 중지됩니다.

## 실행

기존 `practice/hand_detection_fingers.py`가 실행되는 Python 환경을 사용하세요. 필요한 패키지는 OpenCV, NumPy, MediaPipe, Pillow입니다. Jetson에서는 JetPack이 제공한 OpenCV/GStreamer 환경을 유지하고, 노트북의 MediaPipe 설치 안내를 따르세요. Pillow가 없다면 같은 환경에 추가합니다.

```bash
python -m pip install Pillow
```

일반 PC에 새 환경을 만드는 경우에는 다음 패키지가 필요합니다.

```bash
python -m pip install opencv-python numpy mediapipe Pillow
```

macOS에서는 iPhone을 Continuity Camera로 쓸 수 있습니다. 이 환경의 OpenCV에는 GStreamer가 없으므로 `--pipeline` 대신 `--camera` 번호를 씁니다.
- OpenCV는 카메라를 `uniqueID` 문자열 순으로 번호를 매깁니다. 2026-10-18 기준으로 iPhone이 연결되어 있으면 0번이 iPhone, 1번이 내장 카메라입니다. iPhone 연결이 끊기면 0번이 내장 카메라가 됩니다.
- iPhone은 잠근 상태로, 후면 카메라가 손을 향하게 고정합니다.
- 처음 실행할 때 터미널 앱에 카메라 권한을 허용해야 합니다.
- MediaPipe는 수업 노트북처럼 `--no-deps`로 설치합니다. 의존성을 함께 설치하면 `opencv-contrib-python`이 따라 들어와 기존 OpenCV와 충돌합니다.

```bash
python -m pip install --no-deps mediapipe
python -m pip install absl-py flatbuffers sounddevice certifi
```

아래 명령은 리포지토리 루트 `Vision-LLM-202035152` 기준입니다.

```bash
# 일반 USB 웹캠
python 261018/project01.py

# practice에서 쓰던 USB GStreamer 파이프라인
python 261018/project01.py --pipeline usb

# 밝기 보정 + 피부색 분할/윤곽선 보기
python 261018/project01.py --pipeline usb --enhance --show-mask

# 왼손만 사용 / 카메라 변경 (macOS: 1번이 맥북 내장 카메라)
python 261018/project01.py --hand left --camera 1

# 누르기 판정 거리(mm) 조절
python 261018/project01.py --tap-enter 15 --tap-exit 23

# 오른손만 사용 (기본은 양손)
python 261018/project01.py --hand right

# 카메라 없이 한글 조합만 시연 (외부 패키지도 필요 없음)
python 261018/project01.py --demo
```

`--demo`는 `안녕하세요`를 출력합니다. 모델은 현재 작업 디렉터리에 관계없이 리포지토리의 `src/models/MediaPipe/hand_landmarker.task`에서 찾습니다. 기본 카메라는 USB 0번이며, CSI 카메라를 사용하면 `--pipeline 'nvarguscamerasrc ... ! appsink ...'`로 해당 장치의 GStreamer 문자열 전체를 넘기세요.

한글 폰트는 Noto CJK, 나눔고딕, 맑은 고딕, Apple SD Gothic Neo의 일반 설치 경로에서 찾습니다. 폰트가 없으면 `--font /경로/한글폰트.ttf`를 지정하세요. Ubuntu의 Noto CJK 패키지는 `fonts-noto-cjk`입니다.

## 입력 방법

1. 손바닥을 카메라로 향하고 손가락을 적당히 벌립니다.
   - 기본 `--hand both`는 양손을 동시에 인식하고, 각 손의 엄지로 그 손의 키를 입력합니다.
   - `--hand left`/`--hand right`는 한 손만 씁니다.
2. 엄지로 원하는 마디를 한 번 누릅니다. 닿은 상태가 **0.05초** 유지되면 그 키가 한 번 입력됩니다.
3. 다음 키를 누르기 전에 엄지를 손가락에서 뗍니다. 떨어진 거리가 판정 거리보다 커야 다음 입력을 받습니다.
4. 주먹을 **0.18초** 쥐면 마지막 입력 한 번이 지워집니다.
   - 주먹을 계속 쥐어도 한 번만 지웁니다.
   - 손을 다시 펴야 다음 지움을 받습니다.
5. 같은 자음 키를 **0.85초 이내**에 다시 누르면 다음 자음으로 순환합니다. 같은 그룹의 자음을 따로 넣으려면 0.85초보다 길게 기다리거나 소지 뿌리마디(확정)를 누릅니다.

**누르기 판정 방식**
- 엄지 끝과 마디 선분 사이의 거리를 MediaPipe world 좌표(손 중심 기준, 미터 단위)로 잽니다.
- 이 거리가 `--tap-enter`(기본 12mm) 안이면 누른 것으로 보고, `--tap-exit`(기본 20mm) 밖으로 떨어지면 다음 입력을 받습니다.
- 화면상 2D 거리로는 엄지를 띄운 것과 누른 것을 구분할 수 없어서 world 좌표를 씁니다. world 좌표의 깊이 값도 모델이 추정한 값이라 오차가 있습니다.
- 실행 중 `]`로 판정 거리를 늘리고 `[`로 줄입니다(1mm 단위).
  - 잘 안 눌리면 `]`를 누릅니다.
  - 닿지 않았는데 입력되면 `[`를 누릅니다.

**상태 관리**
- 양손의 상태는 따로 관리합니다.
- 손이 사라지거나 일시정지했다가 돌아오면, 엄지를 한 번 떼야 입력을 받습니다.
- 주먹을 쥐는 동안 엄지가 마디에 닿아도 입력하지 않습니다.
- 두 손이 같은 좌우 라벨로 분류된 프레임에서는 표시만 하고 입력은 보류합니다.
- 카메라 프레임이 끊기면(iPhone을 움직이는 경우 등) 최대 10초 기다리고, 그동안의 상태는 초기화합니다.

## 천지인 조합

현대 한글 모음 21개, 자음 순환, 초성·중성·종성 조합, 겹받침, 다음 모음으로 받침 이동을 지원합니다. 아래아 `ㆍ`와 `ㆍㆍ`는 모음 조합 중에 임시 표시됩니다. `지움`은 마지막 키 입력 한 번을 취소합니다. 예를 들어 `가`에서 한 번 지우면 `기`, 다시 지우면 `ㄱ`이 됩니다.

| 입력 예 | 키 번호 | 결과 |
| --- | --- | --- |
| ㄱ + ㅣ + ㆍ | 4, 1, 2 | 가 |
| ㅇ + ㅣ + ㆍ + ㄴ | 0, 1, 2, 5 | 안 |
| ㄱ + ㆍ + ㅡ + ㅣ + ㆍ | 4, 2, 3, 1, 2 | 과 |
| ㅜ + ㆍ + ㅣ | 3, 2, 2, 1 | ㅝ |

물리 키보드로도 같은 조합을 시험할 수 있습니다. 영상 창에 포커스를 두세요.

| 키 | 기능 |
| --- | --- |
| `1`~`9`, `0` | 대응하는 천지인 키 |
| `-` | 공백 |
| `=` / Backspace | 마지막 입력 취소 |
| Tab | 조합 경계 확정 (공백 없음) |
| Enter | 줄바꿈 |
| P | 손 입력 일시정지/재개 |
| H | HUD 도움말 열기/닫기 (닫은 뒤 엄지를 한 번 떼야 입력) |
| E | LAB 명도 보정/필터 켜기·끄기 |
| M | 피부색 영역/윤곽선 표시 켜기·끄기 |
| `[` / `]` | 누르기 판정 거리 1mm 감소/증가 |
| S | `261018/project01_output.txt` 저장 (다시 저장하면 덮어씀) |
| Q / Esc | 종료, 터미널에 최종 입력 결과 출력 |

저장 위치는 `--output /경로/결과.txt`로 바꿀 수 있습니다. 종료만으로 파일이 자동 저장되지는 않습니다.

일부 GTK/Wayland 환경에서는 OpenCV 창의 표시 여부 조회를 지원하지 않습니다. 이 경우 `-1` 반환이나 조회 오류를 종료 조건으로 취급하지 않으며, 영상 창에 포커스를 두고 Q/Esc로 종료하세요. 일반 종료 시 터미널에 종료 이유도 표시합니다.

## 누르기 판정 방식 비교용 기록·평가 (선택)

`project01.py`는 `seg/world` 방식을 씁니다. 다른 판정 방식이나 임계값이 더 나은지는 카메라를 고정한 상태에서 기록한 데이터로 비교할 수 있습니다. 키 위치는 검지(I)·중지(M)·약지(R)·소지(P)의 끝(1)·중간(2)·뿌리(3) 마디 12곳입니다.

**기록**
- 화면에 강조된 마디를 안내에 맞춰 다음 중 하나로 다룹니다.
  - 누르기: 한 번 누릅니다.
  - 근접: 가까이 갔다가 닿지 않고 돌아옵니다.
  - 띄우기: 닿지 않게 띄우고 멈춥니다.
  - 주먹: 주먹을 쥐었다 폅니다.
- 준비 단계에서는 엄지를 손가락에서 뗍니다.
- 기본 설정은 누르기 60회, 근접 24회, 띄우기 12회, 주먹 5회, 자유 동작 3회이고 약 4분 30초가 걸립니다.
- `oblique`는 iPhone을 엄지 쪽에 두고 손바닥 정면에서 약 45° 돌린 위치입니다. 손까지의 거리는 `front`와 같게 둡니다.
- 녹화는 밝은 곳에서 합니다. 어두우면 iPhone이 24fps 이하로 떨어집니다. 저장 후 `meta.json`의 `fps`를 확인합니다.

```bash
python 261018/tap_record.py --hand right --placement front    # 손바닥 정면
python 261018/tap_record.py --hand right --placement oblique  # 엄지 쪽에서 비스듬히
```

기록 중 키 조작
- `Space`: 일시정지. 다시 누르면 현재 시행을 준비 단계부터 다시 합니다.
- `R`: 안내와 다른 동작을 했을 때 씁니다.
  - 수행 중에 누르면 현재 시행을 기록하지 않고 준비 단계부터 다시 합니다.
  - 준비 중에 누르면 직전 시행을 무효로 표시하고 대기열 끝에 다시 넣습니다.
- `Q` / `Esc` / Ctrl+C: 저장하고 종료합니다.
- 손이 수행 구간의 30% 넘게 보이지 않으면 그 시행은 자동으로 무효 처리하고 다시 넣습니다. 같은 시행은 3번까지만 다시 합니다.
- 화면에 손이 하나만 있으면 MediaPipe 좌우 라벨과 상관없이 그 손을 씁니다. 비스듬한 위치에서는 좌우 라벨이 뒤집힐 수 있기 때문입니다. 평가 출력에 세션별 뒤집힘 비율이 나옵니다.

세션은 `261018/data/tap/<시각>-<손>-<위치>/`에 저장되며 git에 포함하지 않습니다(손 영상 포함). 저장 파일은 다음과 같습니다.
- `frames.npz`: 프레임별 시각, 이미지·world landmark, 좌우 라벨
- `trials.json`: 시행 구간과 정답 마디
- `meta.json`: 카메라, 해상도, 실측 fps
- `video.mp4`: MediaPipe에 넣은 프레임

**평가**

```bash
python 261018/tap_eval.py 261018/data/tap/* --detector all --confusion
```

- (손, 카메라 위치) 묶음마다 가장 늦은 세션을 평가용으로 떼어 둡니다. 나머지 세션에서 grid search로 임계값을 고르고, 평가용 세션의 지표를 출력합니다.

  - `point2d`: 기존 방식. 2D 거리로 마디 중점에 머무르면 입력
  - `seg/world`, `seg/image`: 엄지 끝과 마디 선분 사이 거리에 히스테리시스 적용. 거리는 world 좌표 또는 이미지 좌표로 잽니다.
