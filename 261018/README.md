# 손마디 천지인 입력기

엄지 끝을 같은 손의 다른 손가락 마디에 갖다 대면 천지인 키가 입력되는 카메라 프로젝트입니다. 카메라 영상 위에 손마디 자판과 한글 입력 결과를 HUD로 표시하며 `S`로 UTF-8 텍스트 파일에 저장합니다. 다른 프로그램에 키 입력을 전달하는 OS 입력기는 포함하지 않습니다.

## 손 위 키 배치

손바닥이 카메라를 향하도록 손을 세우고 손가락을 편 상태에서 사용합니다. **검지·중지·약지가 세 열**이며, **손끝 → 끝쪽(DIP) → 가운데(PIP) → 뿌리(MCP)**가 위에서 아래로 네 행입니다. 엄지 끝은 MediaPipe landmark 4번입니다. 소지에는 키를 배치하지 않습니다.

| 위에서 아래 | 화면 왼쪽 열 | 가운데 열 | 화면 오른쪽 열 |
| --- | --- | --- | --- |
| 손끝 · 모음 | 1: ㅣ | 2: ㆍ | 3: ㅡ |
| 끝쪽 관절 · 자음 | 4: ㄱ→ㅋ→ㄲ | 5: ㄴ→ㄹ | 6: ㄷ→ㅌ→ㄸ |
| 가운데 관절 · 자음 | 7: ㅂ→ㅍ→ㅃ | 8: ㅅ→ㅎ→ㅆ | 9: ㅈ→ㅊ→ㅉ |
| 뿌리 관절 | 공백 | 0: ㅇ→ㅁ | 지움 |

왼손·오른손 모두 화면에서 왼쪽부터 `ㅣ · ㅡ`로 읽히도록 세 손가락의 뿌리 좌표로 좌우 열을 정합니다. 따라서 손을 바꾸어도 보이는 배열은 같고, 같은 키가 놓이는 실제 손가락은 달라질 수 있습니다. 손끝의 움직임이 열 순서를 바꾸지 않도록 MCP 위치를 기준으로 삼습니다.

각 손끝/관절 중앙에 `ㅣ`, `ㆍ`, `ㅡ`, `ㄱㅋ`, `ㄴㄹ`처럼 실제 자판 글자를 작은 원형 키로 표시합니다. 키의 위치와 크기는 손의 이동과 마디 간격을 따라갑니다. `project01.py`의 `ROWS`가 기본 배열이며, `key_layout`이 화면상의 열과 실제 landmark를 연결합니다.

영상 크기를 유지하며 별도 패널 없이 UI를 합성합니다. visionOS의 [유리 재질](https://developer.apple.com/design/human-interface-guidelines/materials)과 [원형·캡슐 버튼](https://developer.apple.com/design/human-interface-guidelines/buttons)을 참고해, 중성 톤의 반투명 재질과 얇은 반사 테두리를 사용합니다. 유리 표면 안의 영상만 살짝 흐리게 합니다. 인식된 양손에는 옅은 손바닥 mesh·관절 연결선과 왼손/오른손 이름을 표시하고, 각 엄지 끝에는 흰색 링과 점으로 인디케이터를 표시합니다. OpenCV/Pillow로 표현한 2D 스타일이며 visionOS 네이티브 재질은 아닙니다.

상단 입력창은 내용에 맞춰 폭이 변하는 작은 캡슐이며 **현재 줄의 끝부분 한 줄**만 보여줍니다. 긴 줄의 앞부분은 `…`로 생략해도 전체 입력은 조합기에 보존되고 S로 저장됩니다. 각 손의 엄지와 가장 가까운 키는 접촉 전부터 밝아지고 최대 30% 커지며, 크기는 짧게 보간해 부드럽게 전환합니다. 이 시각적 확대는 입력 판정 범위를 바꾸지 않습니다. 실제 접촉 유지 시간은 얇은 원형 진행 표시로, 입력 완료는 짧은 흰색 점등으로 표현합니다. 손을 찾는 중·엄지 해제 필요·일시정지 상태에만 짧은 안내를 표시하고 저장 알림은 2.5초 뒤 사라집니다. `H`로 전체 도움말과 진단 정보를 확인할 수 있으며, 도움말을 연 동안 손 입력은 중지됩니다.

## 실행

기존 `practice/hand_detection_fingers.py`가 실행되는 Python 환경을 사용하세요. 필요한 패키지는 OpenCV, NumPy, MediaPipe, Pillow입니다. Jetson에서는 JetPack이 제공한 OpenCV/GStreamer 환경을 유지하고, 노트북의 MediaPipe 설치 안내를 따르세요. Pillow가 없다면 같은 환경에 추가합니다.

```bash
python -m pip install Pillow
```

일반 PC에 새 환경을 만드는 경우에는 다음 패키지가 필요합니다.

```bash
python -m pip install opencv-python numpy mediapipe Pillow
```

아래 명령은 리포지토리 루트 `Vision-LLM-202035152` 기준입니다.

```bash
# 일반 USB 웹캠
python 261018/project01.py

# practice에서 쓰던 USB GStreamer 파이프라인
python 261018/project01.py --pipeline usb

# 밝기 보정 + 피부색 분할/윤곽선 보기
python 261018/project01.py --pipeline usb --enhance --show-mask

# 왼손만 사용 / 카메라 변경
python 261018/project01.py --hand left --camera 1

# 오른손만 사용 (기본은 양손)
python 261018/project01.py --hand right

# 카메라 없이 한글 조합만 시연 (외부 패키지도 필요 없음)
python 261018/project01.py --demo
```

`--demo`는 `안녕하세요`를 출력합니다. 모델은 현재 작업 디렉터리에 관계없이 리포지토리의 `src/models/MediaPipe/hand_landmarker.task`에서 찾습니다. 기본 카메라는 USB 0번이며, CSI 카메라를 사용하면 `--pipeline 'nvarguscamerasrc ... ! appsink ...'`로 해당 장치의 GStreamer 문자열 전체를 넘기세요.

한글 폰트는 Noto CJK, 나눔고딕, 맑은 고딕, Apple SD Gothic Neo의 일반 설치 경로에서 찾습니다. 폰트가 없으면 `--font /경로/한글폰트.ttf`를 지정하세요. Ubuntu의 Noto CJK 패키지는 `fonts-noto-cjk`입니다.

## 입력 방법

1. 손바닥을 카메라로 향하고 손가락을 적당히 벌립니다. 기본 `--hand both`는 왼손과 오른손을 동시에 인식합니다. 양손 각각에 자판과 엄지 인디케이터가 나타나며 같은 손의 엄지로 그 손의 키를 입력합니다. `--hand left/right`는 한 손만 사용하고, 이전의 `--hand auto`도 이제 양손 모드로 동작합니다.
2. 엄지를 모든 키 범위 밖으로 떼어 준비합니다.
3. 원하는 관절에 엄지 끝을 **0.12초** 유지하면 한 번 입력됩니다. 원형 키 주변의 진행 표시와 입력 완료 시 흰색 점등을 확인하세요.
4. 다시 입력하려면 엄지를 모든 키에서 충분히 떼고 **0.10초** 기다립니다. 붙인 채 다른 키로 미끄러뜨려도 연속 입력되지 않습니다.
5. 같은 자음 키를 **0.85초 이내**에 다시 누르면 순환합니다. 같은 그룹의 자음을 별도로 넣으려면 0.85초보다 길게 기다리거나 `Tab`으로 확정하세요.

자음 순환 시간은 두 **입력 이벤트 사이**의 시간입니다. 천천히 동작할 때는 `--cycle 1.5`처럼 늘리면 됩니다. 양손의 접촉/해제 상태는 별도로 관리해 한 손을 붙인 채 다른 손으로 입력할 수 있습니다. 감지 중 손이 사라지거나 일시정지했다가 돌아온 경우에도 해당 손의 엄지를 한 번 떼어야 다시 입력됩니다. 검출 순서가 바뀌어도 왼손/오른손 상태를 유지합니다. 두 손이 같은 좌우 라벨로 분류된 프레임에서는 표시만 하고 입력은 잠시 보류합니다.

카메라 한 대에서는 실제 피부 접촉을 측정할 수 없으므로 **화면에서 엄지 끝과 관절이 가까운지**로 접촉을 추정합니다. 손바닥 크기에 비례해 범위를 조절하고, 이웃 관절의 간격으로 최대 반경을 제한합니다. 손을 옆으로 세우거나 가리면 오입력할 수 있습니다. 작은 손은 입력을 중지하므로 화면에 손을 더 크게 보이게 해주세요.

접촉 판정이 어렵다면 실행 중 `]`로 반경을 늘리고 `[`로 줄이세요. 이웃 마디 간격에 따른 상한에 도달하면 더 커지지 않습니다. `--dwell 0.20 --release 0.15`로 유지 시간을 늘리면 짧은 흔들림을 줄일 수 있습니다.

## 천지인 조합

현대 한글 모음 21개, 자음 순환, 초성·중성·종성 조합, 겹받침, 다음 모음으로 받침 이동을 지원합니다. 아래아 `ㆍ`와 `ㆍㆍ`는 모음 조합 중에 임시 표시됩니다. `지움`은 마지막 키 입력 한 번을 취소합니다. 예를 들어 `가`에서 한 번 지우면 `기`, 다시 지우면 `ㄱ`이 됩니다.

| 입력 예 | 키 번호 | 결과 |
| --- | --- | --- |
| ㄱ + ㅣ + ㆍ | 4, 1, 2 | 가 |
| ㅇ + ㅣ + ㆍ + ㄴ | 0, 1, 2, 5 | 안 |
| ㄱ + ㆍ + ㅡ + ㅣ + ㆍ | 4, 2, 3, 1, 2 | 과 |
| ㅜ + ㆍ + ㅣ | 3, 2, 2, 1 | ㅝ |

물리 키보드로도 같은 조합을 시험할 수 있습니다. 영상 창에 포커스를 두세요.

| 키 | 기능 |
| --- | --- |
| `1`~`9`, `0` | 대응하는 천지인 키 |
| `-` | 공백 |
| `=` / Backspace | 마지막 입력 취소 |
| Tab | 조합 경계 확정 (공백 없음) |
| Enter | 줄바꿈 |
| P | 손 입력 일시정지/재개 |
| H | HUD 도움말 열기/닫기 (도움말을 닫은 뒤 엄지를 떼어 재입력 준비) |
| E | LAB 명도 보정/필터 켜기·끄기 |
| M | 피부색 영역/윤곽선 표시 켜기·끄기 |
| `[` / `]` | 접촉 반경 감소/증가 |
| S | `261018/project01_output.txt` 저장 (다시 저장하면 덮어씀) |
| Q / Esc | 종료, 터미널에 최종 입력 결과 출력 |

저장 위치는 `--output /경로/결과.txt`로 바꿀 수 있습니다. 종료만으로 파일이 자동 저장되지는 않습니다.

일부 GTK/Wayland 환경에서는 OpenCV 창의 표시 여부 조회를 지원하지 않습니다. 이 경우 `-1` 반환이나 조회 오류를 종료 조건으로 취급하지 않으며, 영상 창에 포커스를 두고 Q/Esc로 종료하세요. 일반 종료 시 터미널에 종료 이유도 표시합니다.

## 수업 내용과 연결

| 수업 기술 | 이 프로젝트의 적용 |
| --- | --- |
| 이미지 조정 | 좌우 반전, 필요 시 `--flip-vertical` 상하 반전 |
| 색공간 변환 | MediaPipe용 BGR→RGB, 명도/피부색 처리용 LAB |
| Image Enhancement·필터링 | E: LAB L 채널 CLAHE 및 Gaussian blur |
| Color Segmentation·형태학 연산 | M: 손바닥 샘플의 LAB a/b 범위, 손 영역 마스크, opening/closing |
| Contour Detection | M: 피부색 마스크의 외곽선 overlay |
| 객체 추적·신체 인식 | MediaPipe VIDEO 모드로 손 landmark 추적 |
| 관계성과 결과 표현 | 엄지-관절 거리, 접촉 상태/입력 진행 표시, 한글 텍스트 |

피부색 분할은 관측 영역을 설명하는 보조 시각화입니다. 조명/피부색에 따라 달라지므로 키 입력을 차단하는 조건으로 사용하지 않습니다. 명도 보정과 마스크 표시도 각각 끌 수 있습니다. MediaPipe VIDEO 모드와 `detect_for_video`는 [공식 Python 안내](https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker/python)의 API를 사용합니다.
